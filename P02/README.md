## Схема «звезда»

В центре — таблица фактов `fact_sales` (продажи). Вокруг — 5 справочников `dim_*`.

**Одна строка в `fact_sales` = одна позиция в чеке** (ключ: `sale_id` + `product_id`).

### Таблицы

| Таблица | Что внутри |
|---------|------------|
| `fact_sales`   | продажи: кто, что, когда, сколько, по какой цене |
| `dim_customer` | клиенты (ФИО, пол, возраст, город, карта лояльности) |
| `dim_product`  | товары (название, категория, бренд, цена) |
| `dim_store`    | магазины (название, регион, город, адрес) |
| `dim_date`     | календарь (год, месяц, квартал, день недели) |
| `dim_payment`  | типы оплаты (карта, наличные, онлайн) |

### Как связаны

Факт ссылается на справочники по ключам:

| В факте | Куда ведёт |
|---------|------------|
| `customer_id`  | `dim_customer.customer_id` |
| `product_id`   | `dim_product.product_id` |
| `store_id`     | `dim_store.store_id` |
| `payment_type` | `dim_payment.payment_type` |
| `sale_datetime`| `dim_date.date_key` (по дате продажи) |

### Метрики (что считаем)

- `quantity` — сколько единиц товара
- `unit_price` — цена за единицу
- `total_amount` — сумма позиции
