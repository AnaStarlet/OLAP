# З09. Сводная таблица под график

## График
Будущий виджет: «Оборот по месяцам».
Одна строка сводки = один месяц + один магазин (данные хранятся с разбивкой по магазинам, но на графике суммируются в общую линию по месяцам).

Поля: year, month_num, store_id, store_name, amount_sum.

## Доказательство сверки (Сводка = Детальная таблица)

### 1. Общий оборот (без фильтров)
- Сумма из детальной таблицы `fact_sales`: **3 557 661 372.99**
- Сумма из сводной таблицы `sales_by_store_month`: **3 557 661 372.99**
- *Вывод:* Сводка полностью соответствует детальным данным.

### 2. Оборот за январь 2024 (проверка разреза)
- Сумма из детальной таблицы `fact_sales` (WHERE date_id BETWEEN 20240101 AND 20240131): **45313454.57**
- Сумма из сводной таблицы `sales_by_store_month` (WHERE year = 2024 AND month_num = 1): **45313454.57**
- *Вывод:* Разрез по месяцам в сводке работает корректно.

## Как пересчитать сводку
После каждой загрузки детальных данных сводка пересобирается полностью скриптом `sql/summary_fill.sql` (TRUNCATE + INSERT SELECT). Для 100 000 строк это занимает менее секунды, поэтому полный пересчёт проще и надёжнее инкрементального.
